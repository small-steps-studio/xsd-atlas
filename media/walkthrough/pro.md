## Pro: compare, document, flatten

The Pro features run inside a free 14-day trial that starts the first time you use one. The trial is recorded only on this computer and needs no account, key or network.

* **Compare Schema With Another File**, **Compare Two Schema Folders**, **Compare With Git Revision**: every change is listed in the Schema Comparison view as BREAKING, NON-BREAKING or DOCUMENTATION, and **Export Comparison Report** writes it as Markdown, HTML or CSV.
* **Create Full Sample XML**: optional parts, repeated elements, chosen options, realistic values.
* **Create Schema Documentation**: Markdown or HTML reference with a type index.
* **Flatten Schema**: one file per target namespace, includes merged.
* **Create SOAP Envelope Samples**: request, response and fault envelopes for an operation.
* **Create Workspace Schema Inventory**: every schema, who imports whom, missing files and unused types.

To try a comparison: open the sample schema and its version 2, make version 2 the active editor and run **Compare Schema With Another File**, choosing version 1.

After the trial, a one-time licence key keeps Pro: Personal USD 29, Business USD 59 per user.
