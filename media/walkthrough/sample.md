## Sample XML

**Create Sample XML** asks for a global element and opens a new XML document with:

* every required element, as often as `minOccurs` asks,
* every required attribute,
* the first option of each choice,
* default and fixed values where the schema gives them,
* values that satisfy the facets of their type (enumerations, patterns, lengths, ranges, digits).

The Pro command **Create Full Sample XML** also adds the optional parts, repeats elements, lets you pick the option of each choice and uses realistic values with a repeatable seed.
