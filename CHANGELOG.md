# Changelog

## 0.1.0

First release. The free features need no key, no account and no network connection. The Pro features can be tried free for 14 days and are then unlocked with a one-time licence key sold outside the Marketplace.

Free:

* Schema Outline view and document symbols (Outline view, breadcrumbs) for XSD files and for WSDL 1.1 and 2.0 files, including embedded schemas.
* Hover with the resolved definition: base types, facets, content, attributes, occurrence and documentation.
* Go to definition and find references across include, import and redefine, and across the schema files of the workspace.
* Path of the declaration at the cursor in the status bar, with Copy Path At Cursor.
* Structural problems with stable codes (references, names, namespaces, derivation, facets, occurrence values, missing files, WSDL references).
* Create Sample XML: a minimal sample document for a global element.
* Walkthrough, sample files, Report A Problem.

Pro (14-day trial, then a licence key):

* Schema comparison of two files, two folders or a git revision, with every change classified as breaking, non-breaking or documentation, and reports in Markdown, HTML and CSV.
* Create Full Sample XML with optional parts, repeated elements, a choice strategy, realistic values and a seed.
* Schema documentation in Markdown and HTML.
* Flatten Schema into one file per target namespace.
* SOAP 1.1 and 1.2 envelope samples for WSDL operations.
* Workspace schema inventory.
